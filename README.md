# Business & Insurance Info — Starter

This repository contains starter content for an English-language site about business and insurance topics, optimized for WordPress (free budget setup).

Files included in this branch:
- backlog-mvp-wordpress.md — backlog and sprint plan for a WordPress MVP (English)
- article-home-insurance-5-steps.md — sample article (English, SEO friendly)
- schema-article.json — JSON-LD schema for the article
- editorial-calendar-30days.md — 30-day editorial calendar (English)
- wp-theme-starter/style.css — minimal starter theme stylesheet
- wp-theme-starter/functions.php — minimal functions to enqueue style
- README.md — repo overview and installation instructions

How to use:
1. Clone the repo or download the ZIP.
2. To use the sample article: copy the Markdown into a WordPress post (Gutenberg supports pasting Markdown) or convert to HTML and paste in the editor.
3. Install the starter theme in wp-content/themes/wp-theme-starter and activate it (recommended parent theme: a lightweight theme such as Astra or GeneratePress). For a simple start, the starter is sufficient for content display.

Costs and notes:
- My work creating the repo and pushing starter files here is free. However you will likely need to pay for domain registration and hosting if you want a public site (WordPress.com has a free tier but limited features). Plugins and premium APIs may have paid plans.
